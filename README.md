# InvoiceForge

Invoice factoring dApp — **Built on Arc Network**.

## Features

- Create invoices with due dates and factoring fees
- Pay invoices with USDC (auto-approve)
- Request and accept invoice factoring
- FXBlitz score integration for factoring eligibility
- MetaMask connection with auto network switch

## Deploy

1. Fork this repository on GitHub
2. Go to **Settings → Pages**
3. Set **Source** to "GitHub Actions"
4. Push any commit — site deploys automatically to `https://yourname.github.io/invoiceforge-frontend/`
